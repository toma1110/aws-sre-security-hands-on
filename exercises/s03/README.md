# S03 演習：WAFの誤検知を調べ、変更と復帰の条件を決める

正常な注文の一部がWAFで止まったとき、どの通信がどのルールで止まり、変更すると何が通るようになるかを資料から調べます。最後に、対象を絞った例外、期限付き拒否、監視と切り戻しを一つの対応記録にまとめます。

この演習は一人で進められる机上演習です。AWSアカウント、CloudShell、CLI、アプリのデプロイは不要です。AWSリソースを作成・変更・削除せず、リクエストや攻撃も送信しません。この手順によるAWS利用料は発生しません。

## 準備

ブラウザまたはMarkdownを読めるエディタと、記入用のメモを用意します。[記入シート](worksheet.md)を複製するか、同じ項目を紙に書いてください。Section途中から始めても、s02の実行結果やAWS環境は必要ありません。

現行の共通注文受付アプリv1.0.3にはWAF統合がありません。s02で得たCloudWatch Logsはアプリログです。本演習のWAFログ、ACL、rule名、ID、件数、時刻、アプリ結果はすべて教材用の架空資料で、共通アプリの実測ではありません。AWS公式資料は仕様の根拠であり、本ケースの事件や効果を証明するものではありません。

## 進め方（目安12分）

1. [状況と調査資料](scenario.md)の「開始カード」と「資料A〜D」を読みます。解答例はまだ開かず、記入シートの1〜3へ対象、影響、事実と未確認事項を書きます。
2. 資料Eの追加情報を読み、Count観察と限定例外を比べます。記入シート4〜5へ、変える対象、評価順、期待action、残るリスクを書きます。
3. 資料Fを読み、記入シート6〜7へ期限付き拒否、監視、切り戻し、引き継ぎを書きます。選ばない案にも理由を一つ添えてください。
4. 記入後に[解答例と理由](answer-guide.md)を開き、自分の案と比較します。数値の分母、Count後の最終action、例外の対象、期限の担当が違っていたら記録を直します。別案でも、資料にある根拠と残るリスクを説明できれば比較できます。

記入シート7は、影響、証跡、判断、担当・期限、連絡、完了証拠をまとめる共通の対応記録です。このフォルダーの資料だけで、調査から引き継ぎまで進められます。

## 終わるとき

作った記録に「架空演習」、出所、時刻帯、対象、担当、期限、未確認事項を残します。正常通信の回復だけでなく、不審通信を止める確認と、期限付き設定の解除・削除確認まで計画できたかを読み返してください。書いた変更案をAWSへ適用する作業はありません。

AWSリソースや認証情報は作っていないので、AWSの後片付けはありません。メモを保存し、不要な複製だけを削除して終了します。仕様を読み直すときは[公式出典](scenario.md#仕様を確かめる公式資料)の確認日と現行文書を照合してください。
