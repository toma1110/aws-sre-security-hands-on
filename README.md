# 演習資料

この資料は、コース「AWS SREのためのセキュリティ初動と脆弱性対応」で使う、架空の状況を題材にした判断演習です。

演習に登場するサービス、出来事、記録はすべて架空です。資料を読み、考えたことを紙や手元のメモに記録して進めます。AWSアカウントは不要です。AWSへ接続したり、AWS上のリソースを作成・変更したり、攻撃やスキャンを実行したりすることはありません。

演習ごとの説明に沿って、まずシナリオを読み、自分の判断と理由を記録してください。記入例がある場合は、演習を終えてから照らし合わせます。記入例は一つの考え方を示すもので、点数を付けたり、唯一の正解を決めたりするものではありません。

演習メモに、実際のアカウント情報、認証情報、アクセストークン、秘密鍵、顧客情報を書き込まないでください。メモは組織のルールに沿った場所で管理してください。
